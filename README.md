# 🌍 Country Explorer

A beginner-friendly Python project that explores information about countries using a REST API. It fetches real-time country data and allows users to discover useful information about different countries.

## 🚀 Features

- 🌎 Explore countries from around the world.
- 🔍 Search for a country by name.
- 🏳️ View country flags.
- 🏛️ Display capital cities.
- 🌐 Get region and subregion information.
- 👥 View population details.
- 💱 Explore country currencies.
- 🗣️ View languages spoken in each country.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Requests** – To send HTTP requests and retrieve API data.
- **REST Countries API** – To fetch country information.
- **JSON** – To process API responses.

## 🔗 API Used

[REST Countries API](https://restcountries.com/)

This project uses the REST Countries API to retrieve information about countries.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Country-Explorer
```

**3. Install dependencies**

```bash
pip install requests
```

**4. Run the project**

```bash
python main.py
```
